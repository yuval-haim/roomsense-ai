# Data

This repository includes one real room photo supplied by the project author and three deterministic demo variants for testing the pipeline.

For a stronger benchmark, add 50-100 manually annotated real room images to `data/demo_images` and matching JSON files to `data/annotations`.

Recommended annotation labels:

- sofa
- chair
- coffee_table
- dining_table
- television
- tv_console
- large_window
- door
- plant
- cable
- rug
- stroller
- cabinet

Do not commit private home images unless you are comfortable publishing them.
